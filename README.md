# Auditoría de Seguridad — Botium Toys

## Descripción del proyecto

Este proyecto consiste en una auditoría interna de seguridad realizada para Botium Toys, una empresa ficticia dedicada a la venta de juguetes y en expansión hacia el comercio electrónico internacional.

La auditoría fue realizada utilizando el Marco de Ciberseguridad del NIST (NIST Cybersecurity Framework - CSF) con el objetivo de evaluar la postura actual de seguridad de la organización, identificar riesgos y revisar los controles de seguridad y prácticas de cumplimiento existentes.

---

## Alcance de la auditoría

El alcance de esta auditoría incluye:

* Equipos y dispositivos de empleados
* Infraestructura de red interna
* Sistemas y software de la empresa
* Sistemas de comercio electrónico e inventario
* Almacenamiento y retención de datos
* Mantenimiento de sistemas heredados
* Controles de seguridad física

---

## Objetivos de la auditoría

Los principales objetivos de esta auditoría son:

* Identificar los activos de la organización
* Evaluar los controles de seguridad existentes
* Revisar las mejores prácticas de cumplimiento
* Identificar riesgos y vulnerabilidades
* Proponer mejoras para fortalecer la postura de seguridad

---

## Resumen de evaluación de riesgos

Actualmente, Botium Toys presenta varios riesgos de seguridad debido a controles de acceso insuficientes, ausencia de cifrado, falta de sistemas de detección de intrusiones y carencia de planes de recuperación ante desastres.

La puntuación general de riesgo determinada para la organización fue:

**Nivel de Riesgo: 8/10 (Riesgo Alto)**

---

## Controles de seguridad evaluados

Durante la auditoría se revisaron las siguientes áreas:

* Controles de acceso
* Principio de mínimo privilegio
* Cifrado de datos
* Seguridad de red
* Políticas de contraseñas
* Protección antivirus
* Sistemas de detección de intrusiones (IDS)
* Recuperación ante desastres
* Respaldos de información
* Seguridad física

---

## Áreas de cumplimiento revisadas

La auditoría también consideró aspectos relacionados con:

* PCI-DSS
* GDPR
* Privacidad y protección de datos
